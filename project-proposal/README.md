# Project Proposal — CampusPulse

## 1. Problem Statement
Campus life at universities like Thapar Institute is highly vibrant but fragmented. Announcements and events are scattered across informal WhatsApp groups, Instagram stories, posters on campus notice boards, and discord channels. Students struggle with:
- Discovering real-time campus events, workshops, and hackathons.
- Finding exact campus venues and locations.
- Sharing event calendars with friends while maintaining privacy.

## 2. Proposed Solution
CampusPulse addresses this by centralizing:
1. **Interactive Event Feed**: Filtered society notifications and student event feeds with RSVP capabilities.
2. **Interactive Campus Navigation**: Leaflet-powered campus map with categorized location markers and detail sheets.
3. **Smart Calendar & Friends Sync**: 3-tier privacy calendar allowing students to coordinate event attendance with friends.

## 3. Technology Stack
- **Frontend**: React 19, Vite, Tailwind CSS, Leaflet, Framer Motion
- **Backend**: Python FastAPI, SQLAlchemy (Async), SQLite / PostgreSQL
- **Authentication**: JWT authentication with bcrypt password hashing

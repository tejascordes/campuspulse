# CampusPulse — Project Proposal

## Executive Summary

Campus life at higher education institutions such as Thapar Institute of Engineering & Technology (TIET) is vibrant, active, and multi-faceted. However, student coordination suffers from fragmented communication channels — WhatsApp groups, Instagram stories, physical notice boards, and unofficial Discord servers.

**CampusPulse** provides a centralized, unified campus social discovery and navigation platform. By combining a Reddit-style event and society announcement feed, an interactive interactive campus map with Apple Maps-style bottom sheets, and a 3-tier privacy calendar sharing model, CampusPulse enhances campus engagement and student coordination.

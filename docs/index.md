# CampusPulse Documentation

Welcome to the **CampusPulse** project documentation.

## Project Overview

CampusPulse is a campus-centric social and discovery web platform tailored for Thapar Institute students. It connects society announcements, student-organized events, interactive campus navigation, and social calendar sharing.

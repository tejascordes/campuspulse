# Final Project Report (End-Semester SE Lab)

This directory contains the final comprehensive Software Engineering Lab project report for **CampusPulse**, including Object-Oriented UML models, full technical implementation documentation, and testing/verification results.

---

## Deliverables Index

1. [UML Diagrams](uml-diagrams.md):
   - **Class Diagram**: Object structure, entities, relationships, attributes, and methods.
   - **Sequence Diagram**: Detailed message passing for Event RSVP and Map Exploration flows.
   - **Collaboration / Communication Diagram**: Structural interaction between controllers, services, and repositories.
   - **State Chart Diagram**: Lifecycle states of an Event (Draft -> Published -> Ongoing -> Completed -> Archived).
2. [Implementation Details](implementation.md): Frontend architecture, backend service architecture, async database schemas, and REST endpoint contracts.
3. [Testing & Verification](testing.md): Unit tests, integration test suite, API test results, bundle optimization analysis, and performance metrics.

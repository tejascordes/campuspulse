# Prototype Stage Report (Mid-Semester SE Lab)

This directory contains the mid-semester Software Engineering Lab deliverables, documenting requirements engineering, user stories, use-case specifications, and data flow models.

---

## Deliverables Index

1. [Software Requirements Specification (SRS)](srs.md): Formal functional and non-functional requirements, interfaces, and constraints.
2. [User Stories & Acceptance Criteria](user-stories.md): Agile user stories organized by epic and priority.
3. [Use-Case Diagrams & Specifications](use-case-diagrams.md): Mermaid use-case diagrams and detailed actor-system interactions.
4. [Data Flow Diagrams (DFD Levels 0, 1, 2)](dfd-levels.md): Hierarchical data flow representations from context level to detailed process decompositions.

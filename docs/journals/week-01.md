# Week 01 — Project Ideation & Problem Discovery

**Date**: Week 1  
**Author**: CampusPulse Team  
**Focus**: Problem Definition, Stakeholder Analysis, Brainstorming  

---

## 1. Objectives
- Identify key pain points in current campus event communication and navigation at Thapar Institute.
- Define the project vision and high-level scope.
- Formulate stakeholder personas (freshmen, society coordinators, general students).

## 2. Progress Summary
- Conducted informal surveys across 40+ Thapar students regarding event discovery.
- Identified that over 80% of event announcements get buried in high-volume WhatsApp groups.
- Selected core features: Event Feed, Interactive Campus Map, and Social Calendar.

## 3. Challenges & Decisions
- **Challenge**: Deciding between a native mobile app (React Native) vs. responsive Web Application.
- **Decision**: Chose a responsive Web Application (React + Vite) to eliminate download friction for new students and enable fast campus-wide sharing via direct URLs.

## 4. Next Steps
- Formalize Software Requirements Specification (SRS).
- Draft User Stories and Acceptance Criteria.

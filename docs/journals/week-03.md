# Week 03 — UI/UX Wireframing & Design System

**Date**: Week 3  
**Author**: CampusPulse Team  
**Focus**: Design System, Dark Y2K Neon Theme, Component Wireframes  

---

## 1. Objectives
- Establish the visual identity and color palette for CampusPulse.
- Build reusable UI primitives: Navbar, FilterPills, EventCard, SocietyHub, and Modal overlays.
- Ensure high-contrast readability and smooth animations.

## 2. Progress Summary
- Designed the Dark Y2K Neon design system (`#07070b` background with cyan `#06b6d4`, purple `#8b5cf6`, and pink `#ec4899` accents).
- Created interactive filter pills with glowing active states.
- Implemented responsive navigation with bottom-tab bar for mobile and top-bar for desktop viewports.

## 3. Challenges & Decisions
- **Challenge**: Generic light theme felt corporate and unappealing to college students.
- **Decision**: Adopted a cyber/neon dark aesthetic with glassmorphism card borders, which tested significantly higher in student engagement.

## 4. Next Steps
- Implement full-screen Leaflet campus map view with custom pulsating markers.
